# music-recommendation-system
A system to recommend music to users based on the song they like using an ML model.

---

🛠 Tools Used

- Python
- Streamlit
- joblib
- nltk
- Sikit-learn
- Numpy
- Pandas

---


🔍 Project Objective

To find the top 5 songs most similar to the one selected by user by using their lyrics. I used cosine similarity model to obtain the result.
